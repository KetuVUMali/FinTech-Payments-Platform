# FinTech Payments Platform — Static Web Application

A modern, responsive FinTech Payments Platform built with pure static web technologies.

## Tech Stack
- **HTML5** & **CSS3** (with Shining Glass UI Design System)
- **Vanilla JavaScript (ES6+)**
- **Bootstrap 5.3.3** & **Bootstrap Icons 1.11.3**
- **AOS 2.3.4** (Animate On Scroll)
- **Chart.js 4.4.3**

No frameworks, bundlers, or npm runtime dependencies. Works directly in any modern web browser.

## Getting Started
Double-click `index.html` or serve via any static web server to view the website.

### Pages & Navigation
- **Master Landing Page**: `index.html` (Shining Glass layout with interactive telemetry, calculator, developer playground, and full fintech ecosystem)
- **Merchant Authentication**: `login.html` & `signup.html`
- **Transparent Pricing**: `pricing.html`
- **Dashboard Cockpit**: `dashboard/index.html`
  - Transactions: `dashboard/transactions.html`
  - Customers: `dashboard/customers.html`
  - Payouts: `dashboard/payouts.html`
  - Settlements: `dashboard/settlements.html`
  - Invoices: `dashboard/invoices.html`
  - Subscriptions: `dashboard/subscriptions.html`
  - Payment Links: `dashboard/payment-links.html`
  - API Keys: `dashboard/api-keys.html`
  - Webhooks: `dashboard/webhooks.html`
  - Team & Audit Logs: `dashboard/team.html`, `dashboard/audit-logs.html`

## Multi-Theme System
Includes 4 synchronized themes with instant preview and localStorage persistence:
- **Light Crystal**: Shining crystal glass with glossy specular highlights
- **Dark Obsidian**: High-contrast luminous dark glass
- **Midnight Sapphire**: Deep navy financial interface
- **High Contrast**: Accessibility-first contrast mode
