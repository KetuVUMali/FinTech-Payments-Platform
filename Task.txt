# 2. TECHNOLOGY REQUIREMENTS

Use:

* HTML5
* CSS3
* JavaScript ES6+
* Bootstrap 5
* Bootstrap Icons
* AOS (Animate On Scroll)
* Optional GSAP where useful
* Chart.js for charts
* Google Fonts or another professional web font
* CSS Variables
* LocalStorage for demo state/theme persistence
* Vanilla JavaScript architecture

IMPORTANT:

Prefer **Bootstrap utilities and components** wherever practical.

Do not unnecessarily create complicated custom CSS when Bootstrap can handle the requirement.

However, custom CSS is expected for:

* FinTech visual identity
* advanced dashboard layouts
* custom cards
* charts
* sidebar
* theme system
* animations
* data tables
* responsive behavior
* special components
* visual polish

Do NOT use React, Angular, Vue, Next.js, or another framework unless explicitly requested.

The project should work directly in a browser.
